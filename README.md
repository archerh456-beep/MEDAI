# MedAI Academy | أكاديمية الذكاء الاصطناعي والطب التفاعلية 🩺

منصة طبية تعليمية متقدمة مبنية بأحدث التقنيات لطلاب كليات الطب والأطباء المقيمين، تجمع بين العلوم الطبية الأساسية، المحاكاة السريرية لغرف الطوارئ، التقييم المعرفي خماسي الأبعاد (Radar Matrix)، وحلبة التنافس والمسابقات، مع استوديو متكامل للمطور والمشرف الأكاديمي.

---

## 🌟 الميزات الرئيسية للمنصة

### 1. ⚡ استوديو المطور والمسؤول الأكاديمي المتكامل (Developer Studio)
- **حساب المطور المعتمد:** Archerhood (`archerh456@gmail.com`).
- **لوحة المقاييس الأكاديمية (Academic KPIs):** متابعة أعداد الطلاب، متوسط المؤشرات المعرفية، ومؤشرات الأداء.
- **إدارة وبناء المقررات (Curriculum Studio):** إنشاء ونشر وتعديل المقررات والوحدات التفاعلية وتصنيفها حسب السنوات والتخصصات.
- **محرر الحالات السريرية (Clinical Cases Builder):** تصميم سيناريوهات مرضى متكاملة تشمل العلامات الحيوية (Vitals)، تخطيط القلب (ECG)، نتائج التحاليل، ومحطات القرار المتشعبة.
- **بنك الأسئلة والتقييم المعرفي (Cognitive Quiz Builder):** إضافة أسئلة مصنفة حسب الأبعاد المعرفية الخمسة.
- **مدير المسابقات والحلبة (Tournament Manager):** إطلاق تحديات خاطفة مع مؤقتات مخصصة ونقاط مضاعفة.
- **محرر قاعدة البيانات الحي (Live JSON Inspector):** تعديل وحفظ وتصدير بيانات المنصة مباشرة في `src/data/db.json`.
- **مختبر الذكاء الاصطناعي (AI Prompt Sandbox):** توليد محتوى سريري، أسئلة MCQs، وبطاقات استذكار بضغطة زر.

### 2. 🕸️ نظام تقييم القدرات المعرفية بالرادار (Cognitive Radar System)
- تقييم خماسي الأبعاد للمهارات السريرية:
  1. **الأساسيات والتشريح (Foundational Knowledge)**
  2. **التفكير والاستدلال السريري (Clinical Reasoning & Differential Diagnosis)**
  3. **السلامة والعلاج الدوائي (Pharmacology & Patient Safety)**
  4. **سرعة القرار في الطوارئ (Emergency Decision Speed)**
  5. **الطب القائم على الدليل والتفسير المخبري (Evidence-Based Practice)**
- رسم بياني راداري ديناميكي متفاعل (Dynamic SVG Spider Chart).
- تقرير تحليلي يشمل نقاط القوة السريرية، الثغرات المعرفية، وخطة تدريبية مقترحة.

### 3. 🏆 حلبة التنافس والمسابقات الطبية (The Medical Arena)
- **المواجهة المباشرة (Blitz Battle):** أسئلة سريرية عاجلة مع مؤقت تنازلي (20 ثانية لكل سؤال) ومضاعف نقاط Combo Streak (حتى x3.0).
- **لوحة الشرف الوطنية (National Leaderboard):** منصة التتويج للمراكز الثلاثة الأولى (🥇 🥈 🥉) وتصنيف الطلاب بحسب النقاط (XP) والأيام المتتالية (Streaks).
- **نظام الرتب والأوسمة:** من طالب متدرب سريري وحتى استشاري معتمد، مع أوسمة إنجاز قابلة للفتح.

### 4. 🏥 محاكي الحالات السريرية وغرفة الطوارئ (Clinical Simulator)
- محاكاة دقيقة لمرضى الطوارئ (مثل متلازمة الشريان التاجي الحادة STEMI، والحماض الكيتوني السكري DKA).
- جهاز مراقبة حيوية (Bedside Telemetry Monitor) يعرض ضغط الدم، النبض، الأكسجين، ورسم نبضات القلب ECG الحي.
- تفاعل ديناميكي: تتحسن العلامات الحيوية للمريض عند اختيار القرارات الطبية الصحيحة!

### 5. 📚 المقررات والمستكشف التشريحي التفاعلي (Interactive Medical Atlas)
- مقررات مصنفة أكاديمياً (Cardiology, Emergency Medicine, Neuroanatomy, Biochemistry, Pharmacology).
- مستكشف تشريحي وهيموديناميكي تفاعلي للقلب بحجراته الأربع وشرايينه مع لآلئ سريرية مركزة (Clinical Pearls).

### 6. 🎴 بطاقات الاستذكار السريع والتكرار المتباعد (Spaced Repetition)
- بطاقات مراجعة ثنائية الوجه High-Yield USMLE / Board Concepts.
- تقييم مستوى الصعوبة (صعب 🔴، متوسط 🟡، سهل 🟢) لاحتساب تكرار المراجعة.

### 7. 🤖 المساعد السقراطي الطبي بالذكاء الاصطناعي (Socratic AI Tutor)
- محاور سريري ذكي يناقش التشخيص التفريقي، يبسط آليات الأدوية، ويطرح سيناريوهات اختبار سقراطية.
